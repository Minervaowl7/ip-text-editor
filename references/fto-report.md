# FTO报告改稿

以项目约定的交付体例为准。术语与比对方法参照 `T/CIPS 001—2026`，章节组织可参考2026年10月的行业撰写模板（两者的性质与出处见[来源与版本](terminology/sources.md)的R4、R5）。法域、核查时点与结论依据以本项目材料为准。

| 报告位置 | 改稿时核对 |
| --- | --- |
| 项目背景与分析范围 | 写清评估哪款产品或哪个方案版本，在哪个国家或地区拟实施什么行为，以及检索和状态核查截止日；委托人、项目实施方与产品实施主体分别称呼。产品结构细节缺失时，标明缺少哪类图纸或资料。 |
| 技术方案分析 | 分清排查对象、技术点与本次纳入的风险排查点；介绍部件或工艺步骤时，保留连接、组合、顺序、参数等影响侵权比对的技术关系。排查点的划分与编号应能对应到检索和比对章节。 |
| 专利检索与筛查 | 保留数据库、检索范围、检索要素、布尔检索式或其引用位置、检索日期与各阶段筛查数量等复核依据。分清原始命中、去重后记录、通过初筛的候选专利与纳入比对的目标专利；申请公开与授权文献若按统计口径归并，须写明归并规则；同族在不同目标法域的权项与状态分别核对。 |
| 专利分析与风险等级 | 分清技术相关性、授权及维持状态、具体权项比对结论与报告风险等级。按适用文本核对独立权利要求及必要的从属权利要求；比对表保留权项、对应特征、证据位置及“相同”“等同”“不相同且不等同”“缺少/资料不足以判断”等结论。外观设计写清产品类别、设计特征与整体视觉比较。 |
| 结论与建议 | 总体结论必须与相关专利清单、权项比对表和风险分级一致；分别列明需要补证核实、持续跟踪审查、考虑规避设计、评估许可谈判或分析专利稳定性的事项；建议采取的措施与已经完成的动作及结果分开写。 |
| 使用条件或声明 | 说明结论实际受哪些前置条件限制（例如截至某日、仅针对某型号、登记状态未逐件核实或某连接关系缺实物图纸）。合并没有独立信息的重复免责套话；委托要求保留的声明按要求留存，确保改后文字仍能清楚找到排查范围与证据限制。 |

改稿时重点防住以下六类误改：

- **入池不等于侵权**：“目标专利”指通过筛查、需进一步比对的文献，列入清单本身不构成侵权结论；未审结申请须写明申请状态及所比对的公开文本，可按项目规则列为潜在风险或重点跟踪对象。
- **区分未对应、资料不足与状态待查**：分开写“某特征不对应”“现有资料不足以判断是否对应”和“仍需查明专利在目标法域的法律状态”；核查优先顺序落到具体的待核对象与核查动作。
- **写明证据来源，严守分级规则出处**：写清实际比对所据文本是检索平台摘要、同族代表文献还是目标法域正式权利要求书；登记或年费字段空白时写明该来源未列出相应信息。高、中、低风险标签及定义严格来自本项目分级规则；参考行业模板时，不把模板中对某风险等级的括注直接套作本案法律结论。
- **初筛边界与检索未命中**：“初筛未发现需进一步比对的专利”对应初筛范围，“不落入保护范围”必须建立在完整权项比对之上；“未检得相关专利”不推导为绝对不存在在先权利。
- **稳定性与抗辩程序状态**：出现“存在现有技术抗辩线索”“拟评估专利稳定性”“拟请求宣告无效”时，严格保留其所处程序与证据阶段，绝不据此改写为专利已无效或侵权风险已解除。
- **分清第三方侵权排查与己方专利稳定性视角**：己方方案具备“高壁垒、不易被规避”特征，不等于待评估方案不落入保护范围更宽的第三方在先权利要求；原稿混用视角或把“未筛选”记为“高风险为0”时，按授权范围在正文外明确列为待核或据材料校正。

例如，材料仅显示检得一件在审申请与某结构相关、且缺连接方式图纸时，可改写为：“该申请尚未审结，现有资料尚不足以确认该处的连接方式，建议补充内部结构资料后复核，并持续跟踪后续审查及可能授权文本。”若原稿已下过强结论，按主技能中“只润色”或“授权按材料校正”的规则处理。

检索、复筛与法律判断需另据材料支撑；具体词条选词查[报告、检索和统计](terminology/reports.md)与[专利撰写、审查和保护](terminology/patent-substance.md)。
