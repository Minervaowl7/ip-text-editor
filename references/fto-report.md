# FTO 报告改稿

以项目约定的交付体例为准。术语与比对方法参照 T/CIPS 001—2026，章节组织可参考 2026 年 10 月的行业撰写模板。两者的性质和出处见[来源与版本](terminology/sources.md)的 R4、R5。法域、处理时点和结论依据以稿件所涉项目为准。

| 报告位置 | 改稿时核对 |
| --- | --- |
| 项目背景与分析范围 | 写清评估什么产品或方案版本，在哪个国家或地区拟实施什么行为，以及核查时点。委托人、项目实施方和产品实施主体分别称呼。无法确定产品细节时，标明缺少哪类材料。 |
| 技术方案分析 | 分清排查对象、技术点与本次纳入的风险排查点。介绍部件或步骤时，保留连接、组合、顺序、参数等影响比对的关系。排查点的划分及编号应能对应检索和比对章节。 |
| 专利检索与筛查 | 保留数据库、范围、检索要素、检索式或其引用位置、检索日期及筛查数量等复核依据。区分原始命中、去重后的记录、通过筛查的候选和目标专利。申请公开与授权文献可按统计口径归并。同族在不同法域的权项和状态分别核对。 |
| 专利分析与风险等级 | 区分技术相关性、授权及存续状态、具体权项比对结论和报告风险等级。按适用文本核对独立权利要求及必要的从属权利要求。表中保留权项、对应特征、证据位置及相同、等同、不相同且不等同、缺少或未知等判断。外观设计写清产品类别、设计特征和整体视觉比较。 |
| 结论与建议 | 总体结论要与相关专利清单、权项比对和风险分级一致。分别写需要核实证据、持续跟踪、考虑设计调整、评估许可或进一步分析稳定性的事项。建议采取的措施与已有行动和结果分开。 |
| 使用条件或声明 | 说明结论实际受哪些条件限制，例如截至某日、仅针对某型号、登记状态未核实或某项连接关系暂无实物证据。合并无独立内容的重复自保句。委托要求保留的声明按要求处理，排查范围和证据限制应在改后文字中仍能找到。 |

留意以下常见误改：

- “目标专利”表示需要继续比对，筛入该清单不产生侵权结论。未审结申请要标明申请状态及所比对的文本，可依据项目条件列为潜在风险或跟踪事项。
- 分开写“某特征不对应”“现有资料不足以判断是否对应”“仍需查明专利在目标法域的状态”。把核查优先顺序写成待核对象和核查事项，风险等级按原分级规则表达。证据说明写明实际取得的是检索平台记录、同族代表文献还是当地权利要求。登记或年费字段空白时，写明该来源未列出相应信息。所采用的高、中、低等标签及定义来自项目分级规则。引用行业模板时，不把模板中对某一等级的括注套作所有报告的法律结论。
- 做过初筛的案件可写“初筛未发现需要进一步比对的专利”。确实完成了比对的案件才写相应权项结论。“未检得”不推导为不存在相关权利。
- 对“存在现有技术抗辩线索”“拟评估专利稳定性”“拟请求宣告专利权无效”等表述，保留行为和证据所处阶段。不得据此写专利已无效或原风险已解除。

例如，材料只表明已检得一件在审申请与某结构相关，又缺少判断连接方式的资料，可写“该申请尚未审结。现有资料不足以确认连接方式，建议跟踪后续审查及可能的授权文本”。如果原稿已经给出更强结论，按技能入口中只润色或授权校正的规则处理。

检索、复筛和法律判断需另有材料。改稿时具体怎样选词，查[报告、检索和统计](terminology/reports.md)及[专利撰写、审查和保护](terminology/patent-substance.md)。
