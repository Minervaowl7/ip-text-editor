# 专利导航报告改稿

以委托需求、项目类型和交付要求为起点。`GB/T 39551.1—2020` 提供共同框架，第2至6部分按应用场景选用，第7部分用来核对服务事项（出处见[来源与版本](terminology/sources.md)的R3）。

| 项目主要目的 | 对应部分及改稿关注点 |
| --- | --- |
| 区域规划 | 第2部分。区分支撑区域布局与评价区域创新质量；交代区域边界、比较对象与数据口径。 |
| 产业规划 | 第3部分。结合产业链、产业发展与技术态势说明导航结论，必要时以图谱承接已有分析及其关系。 |
| 企业经营 | 第4部分。按投资并购评估、上市准备、合作开发、技术引进或产品开发等具体目标选用内容；候选对象、评价结果与经营决策分开陈述。 |
| 研发活动 | 第5部分。区分评估研发立项与辅助研发过程；保持研发目标、已有分析、候选技术路线及阶段建议的对应关系。 |
| 人才管理 | 第6部分。区分人才遴选与人才评价；专利署名等指标须结合实际贡献材料与评价条件使用。 |
| 服务准备、提供和评价 | 第7部分。涉及项目委托、服务交付或服务评价时，按合同与实际履行情况写，分开说明服务质量与成果运用情况。 |

对照总则第6至9章及第7.2节，逐章核对以下内容：

| 报告内容 | 改稿时核对 |
| --- | --- |
| 需求分析 | 明确报告服务哪项具体决策，界定分析对象、地域、时段与任务范围；报告题目、导言与结论须围绕同一项目需求展开。 |
| 信息采集范围及策略 | 分清专利文献、统计年鉴、行业市场资料与专家访谈等来源；保留足以解释样本边界、数据覆盖和图表含义的必要说明。 |
| 数据处理过程与方法 | 分别交代清洗、筛选和标引规则；保留影响结论的去重单位、申请人归并规则与技术分类口径；对照正文、图表、数据表及图注核对分母、日期与单位。 |
| 分析模型和分析过程 | 说清用哪些数据、指标或关联关系回答项目问题；“分析模型”按实际采用的指标和维度表述。单一趋势图、申请量或数量排名只支持与该指标相称的结论，不拔高推论。 |
| 结论和建议 | 每项结论能回到相应数据、比较范围与分析过程；建议写清拟解决的问题、已有依据、实施对象和可落地动作；已识别现象、拟采取行动与已实现效果分开写。 |
| 成果产出、运用和评价 | 报告、数据集和图谱分别说明；区分已经交付、已被采纳和采纳后产生的实际效果；涉及绩效评价时，按材料写明评价主体、指标与结果。 |

## 怎样写数据、结论、建议与报告语体

- **先说结果与读者口径。** 先给出读者关心的发现，再解释数据依据和适用边界。内部简称能从上下文确定所指时，直接改写为具体对象或结果；所指不清时保留原文并在正文外列为待核。删去与理解结论无关的导出日志、复核批次与流转交代，但在方法说明或图表旁保留影响结果的统计规则。
- **写清计数、去重与归并规则。** 写明按什么单位计数、怎样去重、用什么当分母；专利申请、公开文献与同族各用原单位。技术分支名称与检索表、图例或数据标签对应时保留原名，可在旁边简短释义，不擅自翻译或更名。遇到正文“申请人/权利人/发明人”与图表标题不一致时，保留原统计主体并标为待核。共同申请分别计入各申请人名下时，合计占比必须写明这种计数方式；排名一律以图表实际归并口径为准，集团关联关系未经核实时，把合并试算及相关排名列为待核。
- **写准时间趋势与地域字段。** 趋势描述先明确按申请日、公开日还是授权日归年，并标明检索截止日。已知近18个月公开滞后导致近期申请未全量公开时，保留这一限制，不据此把末尾年份下探写成“创新萎缩”；“目前检得的申请少于上一年”仅描述已检得数据。区分“申请人来源国”与“公开/受理局地域”；涉及产品实际销售地或权利有效地时，回到对应证据核实。
- **对齐摘要、正文与图表数字。** 同一数字在摘要、正文、图表、图注和附表多处出现时，连同截止日、纳入条件、计数单位与分母一并核对。材料明示了两处口径差异的，在两处分别写清；不同检索条件存在结果重叠时，交代交集情况；技术关联判断不得超出文献实际披露内容。数字冲突且原因未明时，保留原值并注明待核位置。
- **让建议紧扣发现。** 材料已给出实际问题、备选方案与验证指标的，按“问题—比较—决策方式”写清；只有专利公开方案的按文献内容陈述。初筛检得相关专利时，写明筛查结果及下一步拟核查的法域、法律状态和权利要求；报告本身已作侵权风险判断的，核对其是否交代了目标法域状态及产品与适用权利要求的比对依据。
- **守住导航报告语体节奏。** 采用“先给数据，再作解释；先界定范围，再比较对象；先形成结论，再提出建议”的紧凑长句结构，不要为了口语感强拆短句或连堆空洞结论；缩写释义与补充口径优先用中文括号 `（）`，少用媒体式破折号插叙；清理无数据支撑的吹水词，但保留“值得注意的是”“旨在”“综上所述”等正常承接词。

优先沿用委托方认可的报告结构。专项部分只用来核对分析要素是否齐备，不为套模板硬补稿件里没有的工作或结论；术语与统计口径查[报告、检索和统计](terminology/reports.md)。
