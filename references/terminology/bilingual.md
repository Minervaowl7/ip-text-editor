# 涉外与中英常见误译

处理涉外实务报告、双语引文或英文专利翻译转述稿时，先看概念对应哪项外国或国际制度，再选贴合目标文体的自然中文。

| 英文原词或常见直译 | 改稿核对与自然写法 |
| --- | --- |
| `prior art`（误译：优先艺术、在先艺术） | 一律改作“现有技术”（涉及外观设计时按语境用“现有设计”）。不要把申请前公开的现有技术与“优先权”或“抵触申请”混为一谈。 |
| `freedom to operate` / `FTO`（误译：自由运行、保证不侵权） | 写成“自由实施”或“专利侵权风险排查”。即使结论为低风险或未检得高风险有效专利，也不能改写成“绝对不会侵权”或“可自由申请专利”。 |
| `claim chart`（误译：索赔表、权利要求清单） | 写成“权利要求比对表”或“技术特征比对表”。仅列出相关技术特征对照，不等同于已经作出落入保护范围或构成侵权的结论。 |
| `office action` / `OA`（误译：办公行为、官方通知） | 写成“审查意见通知书”或首次注明后用 `OA`；注明所指法域及具体审查轮次。收到 OA 或提交答复，均不代表已经授权或最终驳回。 |
| `prosecution history` / `file wrapper`（误译：起诉历史、检控记录） | 写成“审查档案”或“审批历史”，不译作民事/刑事“起诉”。引用禁止反悔原则时，写明申请人具体放弃或限缩了哪项特征，不泛化为整件权利放弃。 |
| `design-around`（误译：围绕设计、设计变更） | 写成“规避设计”或“绕道方案”。在未对调整后的方案重新完成相关权项比对前，不能写成“已完成规避、风险已消除”。 |
| `infringement` vs. `validity` / `stability`（混淆：用稳定性代替侵权） | 严格区分“侵权判定”（产品是否落入权项）与“专利有效性/稳定性”（权项是否容易被无效）。存在现有技术抗辩线索或拟提无效宣告，不等同于专利已无效。 |
| `patent family` / `simple family` / `INPADOC`（混淆：同族当成同一保护范围） | 写明采用“简单同族”还是“扩展同族”口径。同族成员用于技术检索归并，各地授权状态、保护期与权利要求文本仍须逐国核对。 |
| `SEP` / `FRAND`（混淆：声明等于必要且有效） | 写成“标准必要专利”与“公平、合理和无歧视（FRAND）许可条件”。专利权人单方声明为 SEP，不自动等同于经过必要性评估或必然有效。 |
| `exclusive` / `sole` / `non-exclusive license`（高危反义陷阱） | 英美法语境下 `sole license` 通常指许可人仍保留自身实施权但不得另行许可第三方（对应中国法“排他实施许可”）；`exclusive license` 常指排除许可人自身的“独占实施许可”。跨法域合同一律核对约定正文对许可人自用权和再许可权的具体限制，切忌只凭词面套译。 |
| `provisional application`（误译：临时专利） | 写成“临时专利申请”（常见于美国等法域），其本身不直接进入实审授权，主要用作确定申请日与优先权基础；不可改写成“已获临时专利”。 |
| `comprising` / `consisting of` / `configured to` / `operatively coupled to` | 写在**权利要求或合同引文（A档）**中时，必须保留其开放式（包括）、封闭式（由……组成）、结构功能连接（配置为、可操作地连接）边界；放进**报告综述或管理建议（B/C档）**时，把“配置为”“可操作地耦合至”改顺为“用于……”“与……配合连接”。 |
