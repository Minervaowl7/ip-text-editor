# 报告、检索和统计

先写读者需要知道的事实，再写本次能作出的判断。检索记录支持的范围和不确定之处属于实质内容。导出、匹配、归档等内部流程按用户要求处理。以下报告惯例标为〔实务〕。材料和来源见[来源与版本](sources.md)。

## FTO和风险说明

完整报告按 [FTO报告改稿](../fto-report.md) 核对章节之间的对应关系。

| 用语 | 怎样选 |
| --- | --- |
| FTO分析、专利有效性分析、可专利性分析、科技查新 | 按任务目的写明比较对象。考虑产品实施风险、现有权利稳定性、申请能否获权和查新各有问题及证据。〔R1、R2；实务〕 |
| 目标法域、目标市场、实施行为、核查时点 | 例如“核查截至某日拟在德国销售的某型号”。市场名不能直接代替行为发生地或覆盖国家。产品、工艺和供应链环节分别注明。〔R1、I6；实务〕 |
| 项目需求方、项目实施方、产品实施主体 | 委托或提出需求、执行分析、实际制造或销售是不同角色。合同、背景和结论按各自职责写。〔R4 第4、5章；R5 项目背景〕 |
| 排查对象、技术点、风险排查点 | “排查对象”是具体产品或方法，“技术点”指从方案中识别的技术单元，“风险排查点”是其中本次纳入排查的技术点。编号应对应检索和比对。〔R4 第3、6章；R5 项目背景〕 |
| 有效权利、待审申请、值得跟踪的公开申请 | 有效状态按相应登记和时点确认。在审申请可列为跟踪对象，不能写成已具可执行的授权权利。〔P1 第13、34–40条；实务〕 |
| 相关专利、目标专利、待核专利、风险权利要求 | “相关”可来自技术相关性。“目标专利”表示通过筛查、纳入特征比对的对象，其中可能包括未审结申请。作风险判断时写清法域、状态、权项和证据。〔R4 第3、8–10章；R5 专利分析〕 |
| 权利要求版本、特征比对、产品证据、对应关系 | 比对表先确认权项文本，再用照片、规格、说明书等材料逐项对应。图中两部件同时出现时，仍须凭图示或其他证据判断其连接方式。〔P1 第64条；J1；实务〕 |
| 已证实对应、已证实不对应、资料不足 | 按每项证据记结果。材料只能确认部件存在时，写明已经确认的部件及尚待核查的连接方式。〔实务〕 |
| 未发现落入的依据、尚不能判断是否落入、判断不落入 | 三种表述的证据要求不同。只完成初筛时写初筛发现，材料不全时写待核项。已判断不落入时写明依据和适用的版本。〔R1；实务〕 |
| 规避设计、设计备选方案、待验证的差异 | 候选改动按已完成和拟实施分别写。未比对改动后的全套相关权项时，可写“拟调整某结构，调整后需重新比对”。〔实务〕 |
| 有效专利、专利障碍、仅技术相关 | “障碍”带有实际阻碍实施的判断。只有专利记录或技术相关时，可写“检得与某部件相关的专利，尚待核对其在目标国的权利状态和保护范围”。〔R1、I6；实务〕 |
| 专利风险分级、检索优先级、处理建议 | 表明级别由法域、时点、权项或证据哪个因素支撑。给出具体核查事项，如“核对传感器在底座上的固定方式”。〔实务〕 |

## 科技查新、专利导航与咨询

| 用语 | 怎样选 |
| --- | --- |
| 查新项目、查新点、查新要求、检索范围 | 查新点按已确认的科学技术内容写，并保留必须组合的特征。检索范围说明数据库、地域、时间等与结论有关的条件。〔R2〕 |
| 对比文献、对比文件、检索结果 | 查新、专利审查和侵权争议各用本报告体例。把文献公开的内容和本项目内容分别归属，保留文献标识和出处。〔R2；G2 第三、四章〕 |
| 已有报道、未检索到相关报道、未发现相同报道 | 依任务体例和匹配程度写。分清未检得整套技术组合与其中若干特征已见报道。保留检索范围。〔R2；实务〕 |
| 与项目相同、相近、公开部分技术特征 | 写清相同或不同的是哪一结构、步骤、材料或条件。一个文献的单项特征不能改写成整套技术已公开。〔R2；实务〕 |
| 查新结论、技术水平评价、先进性分析 | 按委托类型和采用的指标分开写。未发现相同公开不直接支持“国际领先”。指标对比应写比较条件和对应材料。〔R2；实务〕 |
| 新颖性对比、布尔检索式、创造性与等同区分 | 科技查新评价“国内外有无相同报道”时用“新颖性”而非宽泛“创新性”；正文把`Bool`写全为“布尔检索式”；“等同”属侵权判定概念，不混用于创造性或查新对比评价。〔R2；G2 第三、四章；J1〕 |
| 专利导航、专利态势分析、专利风险分析 | 导航按产业、区域、企业或研发用途写目标。数据集中度、趋势、产业建议和某产品侵权风险各有分析对象。〔R3；实务〕 |
| 信息采集、数据清洗、数据筛选、数据标引 | 信息采集说明来源和范围。清洗、筛选、标引各说明实际规则，分别识别数据规范化、是否纳入样本及细分标签。〔R3 第1部分第6章〕 |
| 分析指标、分析模型、分析结论 | 按实情说明选用的维度、指标关系与结论依据。图表呈现的趋势不能直接写成因果判断。〔R3 第1部分第6.4、7.2节；实务〕 |
| 分析报告、数据集、专利导航图谱 | 按实际交付形态称呼。图谱可展示产业规划分析及其相互关系，不能用图的数量充当分析质量。〔R3 第1部分第7章、第3部分第7章〕 |
| 成果产出、成果运用、绩效评价 | 交付了什么、哪些建议已被采用、应用后取得什么实际效果，分别据材料写明。〔R3 第1部分第7–9章〕 |
| 专利技术分类、人工标引、专利法律状态 | 标引可反映技术主题，法律状态及权利范围须回到相应文献与登记记录。写明技术分支覆盖、标签粒度和统计单位。〔R3、P3；实务〕 |

完整导航稿件按[专利导航报告改稿](../patent-navigation-report.md)核对项目类型、方法说明和成果。

## 检索结果、状态统计和运营指标

| 用语 | 怎样选 |
| --- | --- |
| 未检索到记录、尚未公布、未提出申请 | 检索材料只支持第一项时可写“本次未检索到相关记录”。要陈述后两项，需有能支持该实际情况的其他材料。〔实务〕 |
| 数据库无记录、状态字段为空、已核实无此情形 | 写出字段、来源或核实结果。空白、检索未命中与确认不存在应分别记录。〔实务〕 |
| 申请量、授权量、截至某日的有效量 | 明确计数对象、日期字段、法域、增量或存量口径。“2024年授权量”与“2024年申请中已授权的件数”分别写。〔P1 第28、39、40条；实务〕 |
| 申请年度、授权年度、统计截止日、观察期 | 统计表的标题和分母要一致。叙述年际申请变化时，应保存有意义的服务或政策背景，依授权删除过程性比较。〔实务〕 |
| 授权比例、审结比例、在审占比、未检索到记录占比 | 每个比例标明分母是全部申请、检得记录、已审结案件或其他集合。数据库能查到的记录不必然涵盖全部样本。〔实务〕 |
| 件数、同族数、文献数、申请人数量 | 交代去重所用标识及同族定义。每份公开文本、每项申请和每个同族的统计结果不可混用。〔P3；实务〕 |
| 转让次数、有转让记录的申请或专利件数 | 多次记录可涉及同一申请或专利。写清转让标的及去重后的件数。“变更次数”需说明包含的著录变更类型。〔P1 第10条；实务〕 |
| 质押登记次数、涉及专利件数、现存有效质押登记 | 可写“10件专利有质押登记记录，合计12次”。若要写“截至某日仍处质押登记状态”，另查变更和注销。〔P4；实务〕 |
| 许可备案、实施许可、实际实施 | 备案数、合同许可数和企业实际采用某项技术的情况各据来源。涉及开放许可需写明处于已声明、公告或实施等哪个环节。〔P1 第12、50、51条；P4〕 |
| 曾授权、仍有效、权利终止原因、维持年限 | 保留是否以授权为起点及截至时间。某案未查到终止原因时可写“状态显示已终止，原因未核实”。〔P1 第42–44条；实务〕 |
| 特定企业、关联企业、申请人、统计归并主体 | 申请人照著录记录。归并到某集团或同一主体时，写明归并口径。名称相似不能推出同一主体或共同权属。〔P3；实务〕 |
| 被引用次数、被引次数、引证文献 | 说明被引与引证方向，避免英文直译“前向被引”，防止与“在先文献”混淆。〔R6；实务〕 |
| 专利质量评估、有效专利构成、专利运营情况 | 参照《专利评估指引》选用客观法律、技术、经济指标，不用“权利底座”“质量体检”“评分画像”“权利活度”。〔R6；实务〕 |
| 侵权取证难易度、外部可见特征、内部工艺或算法 | 不用“可取证性”或方向不明的“取证：高/低”，直接标明“较易／中等／较难”并说明核查依据。〔实务〕 |
| 反向工程、拆解还原、商业秘密与专利选择 | 沿用司法解释用语“反向工程”，不用“可逆向性”“易逆向”，分开表述硬件结构与内部工艺、软件算法。〔U2 第14条；实务〕 |
