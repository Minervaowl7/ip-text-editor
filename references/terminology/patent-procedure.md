# 专利程序和著录

先确认所写的是申请、已授予的权利、公开文献还是程序事件。时间以相应文书及指定统计时点为准。条号及版本见[来源与版本](sources.md)。

## 申请、著录和主体

| 用语 | 怎样选 |
| --- | --- |
| 发明、实用新型、外观设计 | “发明创造”可统称三类。“发明专利申请”仅指申请类型为发明的案件。技术方案、授权类型与行业分类分别写。〔P1 第2条〕 |
| 申请专利的权利、专利申请权、专利权 | 涉及谁有权提出申请时，按法条、合同或争议请求用语写。已提出申请及其转让，分别按事实写申请、申请权。已经授权的权利写专利权。〔P1 第6、8、10条〕 |
| 申请人、专利权人、发明人、设计人 | 以对应时点和文书为准。“登记为申请人”只说明登记角色。贡献者、登记的申请人和授权后的权利人可能各不相同。〔P1 第6、8、16条；P2 第14条〕 |
| 发明人署名、创造性贡献、辅助研发工具 | 写明谁作出创造性贡献。参与组织、提供条件或使用人工智能工具，可按事实写入背景或过程说明。发明人栏按自然人的身份要求填写。〔P2 第14条；G1 第一章4.1.2〕 |
| 职务发明创造、非职务发明创造、职务技术成果 | 专利权属与技术合同分别用各自制度的概念。写单位任务、物质技术条件或约定时保留与事实的关系。〔P1 第6–8条；M1 第847、848条〕 |
| 合作完成、接受委托完成、共同申请 | 完成发明创造的关系与申请表上的主体并列分别写。文稿有权属约定时不要省略。〔P1 第8条；M1 第859、860条〕 |
| 奖励、报酬 | 按发明创造被授予专利权、实施及协议约定分别表述。发明人署名也有独立含义。〔P1 第15、16条；P2 第92–94条〕 |
| 申请日、优先权日、首次申请日 | 对照著录项目和程序规则选择日期。按申请年做统计时，写明采用哪个日期，公开文本或授权日期另计。〔P1 第28–30条；P2 第12条〕 |
| 申请号、申请公布号、授权公告号、专利号 | 依原记录和文献阶段选择。字段混合时注明号码类型，如“相关文献号”。CN 文献号的数字及种类代码按原件抄写。〔P3〕 |
| 公布日、授权公告日、法律状态核查日期 | 分别对应申请文本对外公布、授权公告和查询截止时点。“公开（公告）日”可保留为数据库合并字段。〔P1 第34、39、40条；P3〕 |
| 受理、申请文件提交、申请费缴纳 | 写清事件。收到受理通知书时写“已受理”。尚有手续未核实的，分别表述；受理不说明是否公布、进入实审或授权。〔G5 第三章〕 |
| 本国优先权、外国优先权、分案申请 | 优先权和分案的法律关系分别写。“主张优先权”保留请求状态。“享有优先权”须有支持该判断的材料。〔P1 第29–31条；P2 第48–50条；G1 第一章〕 |
| 同日申请、重复授权、放弃实用新型专利权 | “同日双申”仅在明确为同一申请人就同样的发明创造申请发明及实用新型时作为简称。是否授权、声明放弃以及放弃生效都按程序材料写。〔P1 第9条；P2 第47条；G2 第三章〕 |
| 向外国申请专利的保密审查、保密申请 | 前者涉及向外国申请专利前的手续，后者涉及专利申请本身的保密处理。不要用“技术出口许可”代称两者。〔P1 第4、19条；P2 第7–9条；G5 第五章〕 |

## 审查、答复和授权

| 用语 | 怎样选 |
| --- | --- |
| 初步审查、实质审查 | 按专利类型及实际程序写。“已提交实质审查请求”与“已进入实质审查”分别用。实用新型和外观设计的初步审查也有具体审查范围。〔P1 第34–40条；G1〕 |
| 申请公布、请求早日公布、专利授权公告 | 发明申请公布可写“该发明专利申请已公布”。实用新型和外观设计的授权文献用“授权公告”。〔P1 第34、39、40条；G5 第八章〕 |
| 专利预审、快速审查、优先审查、延迟审查 | 写“通过预审”时指预审环节。进入快速审查、获准优先审查和提出延迟审查请求，各自依据相应记录。〔G5 第七章8.2–8.4；P5〕 |
| 在审、审查中、待答复 | 有明确状态时用“处于实质审查阶段”“已发出第一次审查意见通知书”等。台账用“在审”需说明所含阶段和统计时点。〔P1 第34–37条；G2 第八章〕 |
| 审查意见通知书、补正通知书、视为撤回通知书、驳回决定 | 按文书名称和法律效果写。提出缺陷、需要补正、逾期后的程序处理和驳回结论应保留区别。〔G2 第八章；G5 第六章〕 |
| 陈述意见、补正、修改申请文件 | “提交答复”可概括一次行为。需说明文本变化时写明修改对象、页或权项。保留“按通知补正”和“主动修改”的区别。〔P1 第33、37条；G1 第一章；G2 第八章〕 |
| 主动撤回、视为撤回、视为未提出、不予受理 | 分别照录行为、程序对象和文书结论。例如“复审请求视为未提出”不等于原专利申请被视为撤回。〔P1 第32、35、37条；G4 第二章；G5 第三、六章〕 |
| 驳回决定、决定生效、复审请求 | 已发出驳回决定、该决定已生效和当事人申请复审分别写。只知道收到决定时，不补“终局”。〔P1 第38、41条；G4 第二章〕 |
| 授予专利权、办理登记手续、授权公告、专利证书 | 按材料所载里程碑写。仅收到授予专利权通知或登记手续通知时保留文书事实。陈述生效时核对公告。〔P1 第39、40条；G5 第九章〕 |
| 期限届满、请求恢复权利、中止程序 | 写清是哪项期限和程序。提出恢复请求与恢复获准分别报告。中止也有相应决定和范围，避免写成案件终结。〔P2 第5、6条；G5 第七章〕 |

## 复审、无效、登记和权利状态

| 用语 | 怎样选 |
| --- | --- |
| 请求复审、复审决定、撤销驳回决定 | 复审针对驳回决定。撤销驳回后仍须按材料写后续审查；写作时避免把撤销原驳回写成授予专利权。〔P1 第41条；G4 第二章〕 |
| 提出无效宣告请求、受理、口头审理、作出决定 | 各环节分别报告。查到请求或开庭通知时，仍须查决定才能陈述审理结论。〔P1 第45、46条；G4 第三、四章〕 |
| 维持专利权有效、宣告全部无效、宣告部分无效 | 按决定及其文本写清权项。部分无效时，注明其余权项是否维持及按哪份修改文本。结束时核对行政诉讼及后续决定状态。〔P1 第46、47条；G4 第三章〕 |
| 一事不再理、证据及其结合方式、无效理由 | 核对此前决定实际审理的理由、证据与请求。审阅具体案件时分列请求、理由和证据，不用“又提出过无效”代替。〔G4 第三、八章〕 |
| 互联网证据、发布时间、可为公众获得的时间、取证时间 | 先区分披露时间和固定证据的时间。网页日期有争议时，写清来源、页面版本和相应证据，不能以截图日期代替最早可访问日期。〔G4 第八章5.1；L2 第93、94条〕 |
| 授权、维持、终止、放弃、期限届满、无效 | “曾授权”记录历史事件。“有效”需要对应核查时点。期限届满、未缴年费提前终止、书面声明放弃及无效决定分别标注。〔P1 第42–47条；G5 第九章〕 |
| 专利权期限补偿、药品专利权期限补偿 | 按期满计算和实际书面决定判断。提出补偿请求、收到决定和核准补偿天数分别陈述。〔P1 第42条；P2 第77–84条〕 |
| 专利权评价报告、专利证书、专利登记簿副本 | 分别写评价意见、授权凭证和登记事项。评价报告中的结论不代替无效决定。核实当期状态时看登记信息和其他案件材料。〔P1 第66条；G5 第九、十章〕 |
| 著录项目变更、权利转移、专利申请权或专利权转让 | 根据变更原因和标的用词。名称变更不当然涉及权属转移。签署合同、办理登记和取得新登记信息分别写。〔P1 第10条；P2 第15条；G1 第一章〕 |
| 专利权质押登记、变更、注销 | 写清是某次登记、登记变更、注销还是核查时仍有有效登记。资金数额和是否实际放款需另查。〔P4〕 |
| 专利实施许可合同备案、开放许可声明、强制许可 | 依合同、备案、公告或行政决定分别用语。权利仍归谁、谁获准实施及许可限制按各自材料写。〔P1 第12、50–63条；P4〕 |
| 预审备案主体、申请人、专利权人 | 预审备案与专利案件身份各有登记依据。统计以备案主体关联案件时说明归集口径。〔G5 第七章8.3；实务〕 |
