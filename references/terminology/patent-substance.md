# 专利撰写、审查和保护

先识别原稿在谈申请文件、授权条件、无效理由还是侵权比对。保留技术关系和法律判断强度。法条和版本见[来源与版本](sources.md)。

## 申请文件与技术表述

| 用语 | 怎样选 |
| --- | --- |
| 请求书、说明书、说明书附图、说明书摘要、权利要求书 | 各指不同申请文件。写引用位置时注明文件、条号、段号或图号。摘要可用来定位内容，涉及保护范围时应查权利要求及可用的解释材料。〔P1 第26、64条；P2 第19–26条〕 |
| 外观设计图片或照片、简要说明、局部外观设计 | 具体所指按图样、文字说明及目标产品写。区分请求保护部分和用于表示其位置关系的其他部分。〔P1 第2、27、64条；G1 第三章〕 |
| 权利要求书、权利要求、权项 | 整份文件写“权利要求书”，单项写“权利要求1”。“权项”可用于报告或工作表。涉及不同阶段的文本须写明版本。〔P1 第26、64条；P2 第22–25条〕 |
| 独立权利要求、从属权利要求 | 从属权利要求含所引用权利要求的内容及附加限定。比较时沿引用关系核查，勿遗漏引用权项的技术特征。〔P2 第23–25条；G2 第二章〕 |
| 前序部分、特征部分、引用部分、限定部分 | 按权项实际结构写。前序部分的限制也属于该独立权利要求的内容。“其中”“所述”等需要核对所指。〔P2 第24、25条；G2 第二章〕 |
| 技术问题、技术方案、有益效果 | 写清要解决的问题、采用的手段和已说明的结果。避免把“用于降低温度”改成“实测降低了温度”。〔P2 第20条；G2 第二章〕 |
| 技术特征、技术关系、技术方案 | 零件名称、连接方向、介质流向、步骤顺序和参数条件都可能限定方案。改“甲经乙与丙连通”时保留经由乙的关系。〔P2 第22、23条；实务〕 |
| 必要技术特征、附加技术特征、区别特征 | 分别用于完整技术方案、从属限定和与特定对比对象的差别。不要把“有区别”写成“区别特征必不可少”。〔P2 第23、25条；G2 第二、四章〕 |
| 实施方式、实施例、试验例 | 以原文件组织为准。某一实施例写到的数值或部件，不经核对不写成全部实施方式必有。只有实验目的时不写成实验结果。〔P2 第20条；G2 第二章〕 |
| 功能性限定、结构限定、用途限定 | 按权项原文写。“用于过滤”不能改成原文没有的特定滤网结构。“可”与“必须”分别保留。〔G2 第二章；J1〕 |
| 包括、由……组成、至少、任选、以及、或者 | 属于权利要求或合同定义的限定语时保持其开放性、数量、选择和并列关系。引文按原文摘录。改申请草稿时核对语义和修改限度。〔G2 第二、十章；P1 第33、64条〕 |
| 参数范围、上下限、端点、测量条件 | 比对是否同一参数、条件、单位及开闭区间。写“在1至3之间”前核对端点是否包含。勿把“大于”改成“不低于”。〔G2 第三章；实务〕 |

## 授权审查与答复

| 用语 | 怎样选 |
| --- | --- |
| 专利保护客体、授权条件、保护范围 | 分清申请内容是否属于保护客体、是否满足授权条件，以及某权项界定到哪里。三类判断各有依据。〔P1 第2、5、22–26、64条；G2 第一章〕 |
| 诚实信用原则、涉嫌非正常申请、程序处理 | 涉及非正常申请时按通知所列理由、文书和适用依据写。把“收到核查通知”、当事人的说明和主管部门已认定的情形分别交代。〔P1 第20条；P2 第11条〕 |
| 新颖性、创造性、实用性 | 发明和实用新型的授权判断分别陈述。查新、市场可行性或产品性能对比只说明各自范围。〔P1 第22条；G2 第三至五章〕 |
| 现有技术、现有设计、抵触申请 | 按权利类型、公开时间及用于何种判断核对。“抵触申请”依在先申请和在后公开的相应规则使用，勿将其列为评价创造性的现有技术。〔P1 第22、23条；G2 第三、四章〕 |
| 在先申请、优先权文件、对比文件 | “在先”要说明比较日期。原申请、优先权基础文件、审查员引用的对比文件分别称呼。〔P1 第22、29、30条；G2 第三章〕 |
| 单独对比、组合对比、所属技术领域的技术人员 | 写新颖性时逐一核对单份对比文件。写创造性时说明现有技术的启示、结合理由及比较对象。不得把分散披露写成一份材料完整公开。〔G2 第三、四章〕 |
| 最接近的现有技术、区别技术特征、实际解决的技术问题、技术启示 | 分步陈述创造性意见。实际解决的问题依据区别特征的技术效果确定。避免把特征本身写入问题，或把“区别多”写成当然具备创造性。〔G2 第四章第3.2.1.1节〕 |
| 对解决技术问题作出贡献的技术特征 | 按权利要求和技术效果说明贡献。涉及新增了文本限定但该特征未对解决技术问题作出贡献时，沿用指南对创造性影响的语境。勿把其审查评价写成可直接从权项中删去。〔G2 第四章第6.4节〕 |
| 本领域公知常识、技术启示、惯用手段 | “常见”或“容易想到”应有与判断相符的依据。按通知或答复的角色写“审查员认为”“申请人主张”。〔G2 第四、八章〕 |
| 充分公开、清楚、简要、以说明书为依据 | 分清说明书能否使之实现，权项是否清楚简要以及是否得到说明书支持。勿把“清楚”写成“充分公开”或把“支持”写成已被某对比文件公开。〔P1 第26条；G2 第二章〕 |
| 超出原记载范围、修改后保护范围变化 | 申请阶段的原始公开与保护范围比对分别写。无效程序的修改范围依适用规则及文本判断。勿用一条“不得扩大范围”涵盖所有修改限制。〔P1 第33条；G2 第八章；G4 第三章〕 |
| 单一性、总的发明构思、特定技术特征、分案 | 准确写明审查所指的关联性和权项。“一项申请有多个权项”本身不能说明缺乏单一性。〔P1 第31条；P2 第39、48条；G2 第六章〕 |
| 不丧失新颖性的公开、主张优先权 | 两者适用条件及程序有别。写明公开事件及所用制度，避免只写“宽限期内因此有优先权”。〔P1 第24、29、30条；G2 第三章〕 |
| 在先设计、明显区别、整体视觉效果 | 外观设计按确切对象写设计点和整体视觉比较。避免把发明专利的“创造性三步法”名称直接套给外观设计。〔P1 第23、64条；G4 第五章；J1〕 |
| 算法特征、技术特征、算法与应用场景结合 | 指明权项所用手段、场景及解决的问题。该分类自身不能推出保护客体或创造性结论。引用指南案例时保留适用条件。〔G2 第九章〕 |

## 保护范围和行为

| 用语 | 怎样选 |
| --- | --- |
| 保护范围、权利要求解释、说明书及附图 | 发明、实用新型以权利要求的内容为准。说明书及附图可用于解释。日期和文本先查明，尤其是无效决定修改过的权项。〔P1 第64条；J1〕 |
| 被诉侵权技术方案、被分析方案、相关技术特征 | 诉讼材料才使用“被诉”。FTO报告按实际产品、工艺或方案命名。证据只覆盖某一型号时应保留型号限定。〔J1 第7条；实务〕 |
| 字面落入、相同技术特征、等同技术特征 | 写明比对的权项和特征。单个特征相同或相似，不能代替整项比对。主张等同时记清依据和待核项。〔J1 第7条〕 |
| 落入保护范围、构成侵权、存在侵权风险 | 分开核对范围、行为、权利时点及可能适用的例外。分析性意见使用与材料相称的措辞，并写清作判断的主体。〔P1 第11、64、65、75条；J1〕 |
| 制造、使用、许诺销售、销售、进口 | 按实际实施行为和权利类型写。前期销售宣传、交易发生和产品进口是不同事项。海外制造及目标地销售按各法域和行为分别记。〔P1 第11条〕 |
| 现有技术抗辩、现有设计抗辩、无效宣告请求 | 前两项用于侵权争议中的相应抗辩。提出抗辩及其结果不要写成专利已无效。复审无效程序用语见[专利程序和著录](patent-procedure.md)。〔P1 第45、67条；J1〕 |
| 先用权抗辩、合法来源抗辩、权利用尽 | 逐项核对适用事实和效果。合法来源涉及赔偿责任时，勿扩写成行为不侵权或当然可继续实施。〔P1 第75、77条〕 |
| 专利侵权、假冒专利、冒充授权 | 根据行为和认定机关用词。涉及专利标识、专利证书或广告用语时，按证据和适用条款写其问题。〔P1 第65、68条；P2 第101条〕 |
| 警告函、侵权主张、确认不侵害专利权 | 来函提出主张应注明提出方。收到通知、对方提起诉讼及裁判生效分开。〔J2；实务〕 |
| 药品上市许可、药品专利纠纷早期解决、是否落入保护范围 | 写明申请注册的药品、相关专利权和处理程序。法院或行政部门的专利判断与药品上市许可决定分别写。〔P1 第76条〕 |
