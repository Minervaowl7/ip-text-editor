# 合同、证据和争议程序

按文件和程序识别当事人身份。写请求、证据或义务时保留原范围及期限。合同原条款、行政决定和判决引文保持照录。法条和版本见[来源与版本](sources.md)。

## 交易和技术合同

| 用语 | 怎样选 |
| --- | --- |
| 合同订立、合同成立、合同生效、登记生效 | 分别写订立行为、成立事实、合同效力及特定权利变动何时发生。签合同、权利登记、取得登记凭证各有依据。〔M1 第490、502条；P1 第10条〕 |
| 合同无效、撤销、解除、权利义务终止 | 看具体条款、法律事件或裁判结果。写“对方主张解除”时保留主张身份。〔M1 第143–157、557、562–566条〕 |
| 技术开发合同、委托开发、合作开发 | 依据约定和实际任务选用，写清委托关系、分工、成果交付、申请权及保密约定。〔M1 第851–861条〕 |
| 技术转让合同、技术许可合同 | 写明标的是专利权、专利申请权或技术秘密等，及约定的转让、实施或使用行为。〔M1 第862–864条〕 |
| 专利实施许可、技术秘密使用许可、技术秘密转让 | 前两项指许可；转让按合同及实际变动表述。技术材料交付、实施、披露、使用及改进约定分别写。〔M1 第863–874条〕 |
| 让与人、受让人、许可人、被许可人 | 依合同身份选称谓。付费、交付、保密与侵权处理各项义务写清承担者。〔M1 第862–874条〕 |
| 独占实施许可、排他实施许可、普通实施许可 | 概括中国专利实施许可时，核对约定范围内许可人是否可自行实施、是否能另行许可他人。再许可另查约定。英文 exclusive 等译法须结合合同和法域。〔M1 第864条；M2 第25条〕 |
| 再许可、分许可、许可范围 | 沿用合同原词。写清谁许可给谁，以及主体、用途、地域、期限、数量或媒介等已约定条件。〔M1 第864、867、869条；P1 第12条〕 |
| 成果完成人、成果持有者、权利归属 | 沿用合同或法定角色。完成研发、取得技术资料、能自行使用和获得排他性财产权分别陈述。〔M1 第847–849、859–861条〕 |
| 后续改进成果、改进技术、改进成果归属 | 保留“有权分享”“需通知”“可使用”等具体约定及其条件。没有明确约定时将争议写成待核，勿补成共有。〔M1 第875条〕 |
| 技术咨询、技术服务、技术验收 | 说明交付物、服务事项和验收标准。出具报告、技术解决方案、试验结果和验收通过是不同事实。〔M1 第878–884条〕 |
| 许可使用费、转让价款、提成、违约金、赔偿 | 核对付款性质、计算基数、触发条件及币种。建议金额、约定金额和裁判金额分别标注。〔M1 第585、846、866–870条〕 |
| 质押、保全、担保债权、质押登记 | 质押与法院财产保全分别写。债权金额、质押登记数及实际融资区分。〔M1 第440、444条；P4；L1 保全章〕 |
| 职务科技成果、成果转化、自行投资实施、转让、许可 | 科技成果转化项目与知识产权权属登记分别列。转化收入、合同额和预计产出各记口径。〔X4 第2、16条；实务〕 |

## 民事证据和诉讼

| 用语 | 怎样选 |
| --- | --- |
| 原告、被告、第三人、权利主张人、利害关系人 | 根据诉讼或者其他程序身份写。民事原告可能是许可使用人等主体，按权利基础和实际资格书写。〔L1 第一编第五章；P1 第65条〕 |
| 起诉、收案、受理、立案、开庭、裁判 | 每项按程序通知或文书写。“已起诉”可指提交起诉材料，仍须单独说明有无立案等记录。〔L1 第二编第十二章〕 |
| 诉讼请求、事实和理由、争议焦点、裁判主文 | 当事人请求、案件事实和裁判结果分别叙述。简述裁判时保留判决是否生效和适用范围。〔L1 第124条及第二编〕 |
| 举证责任、证明对象、待证事实、证据能力和证明力 | 写清谁主张、证据要证明什么及其局限。能否作为证据使用和证明程度按实际认定或分析区分。〔L1 第六章；L2〕 |
| 书证、物证、视听资料、电子数据、鉴定意见 | 按证据性质和呈现方式选称。截图可作为电子数据的呈现形式，仍应记录来源、取得时间及对应原始数据。〔L1 第66条；L2 第14、15、93、94条〕 |
| 原件、原始载体、输出件、复制件 | 依具体证据和规则写。不能笼统称截图或打印件是原件或伪造件。记录核对方式及不足。〔L2 第15、23条〕 |
| 真实性、合法性、关联性、证明力 | 区分提出、质证和法院的认定。仅指证据不能确认某结构时，直接写资料未显示的具体结构。〔L2；实务〕 |
| 公证取证、证据保全、财产保全、行为保全 | 分清证明材料固定、财产限制和行为命令。保全申请、保全裁定及执行情况按文书写。〔L1 第六、九章；L2〕 |
| 鉴定意见、检验报告、技术调查意见、专家辅助人意见 | 按产生程序和文书题名写。审阅报告可描述技术来源及结论，不能把企业检测单写成法院鉴定。〔L1 第六章；L2；实务〕 |
| 停止侵害、赔偿损失、合理开支、惩罚性赔偿 | 分开写主张、计算依据、法院支持金额和履行要求。诉请某项赔偿不能写成已经判给。〔P1 第71条；T1 第63条；C1 第54条；U1〕 |
| 判决、裁定、调解书、仲裁裁决 | 按正式文书名引用。“裁决”在多个程序有特定含义，别把行政裁决或仲裁裁决通称为法院判决。〔L1；实务〕 |
| 一审、上诉、二审、再审、执行 | 写清文书作出、生效、审理中和执行状态。上诉、申请再审和案件依法进入相应程序分别按材料确认。〔L1 第二、三编〕 |
| 涉嫌侵犯知识产权犯罪、移送、立案侦查、判决有罪 | 依据机关和程序阶段选用。民事侵权事实与刑事定性分开。所涉罪名保持文书原称。〔X7〕 |

## 行政处理、行政复议和行政诉讼

| 用语 | 怎样选 |
| --- | --- |
| 专利侵权纠纷行政裁决、行政处罚、行政调解 | 写出机关处理的是侵权争议、违法行为处罚还是损害赔偿调解。报告中的“处理”需要具体时补明程序与文书。〔P1 第65、68、70条；L3〕 |
| 申请行政复议、专利复审、行政诉讼 | 行政复议依行政复议法，专利复审指对驳回申请决定提请审查。文书中的救济途径以实际告知及适用规定为准。〔P1 第41、46条；L3；L5〕 |
| 行政复议申请人、被申请人、第三人、行政复议机关、行政复议机构 | 用法定程序身份。承办案件的机构与作出决定的机关根据文件分别使用。〔L3 第四条、第二章；L4〕 |
| 复议前置、受理、补正、复议决定 | “经行政复议后方可起诉”只按适用制度写。提交申请、复议机关受理及作出决定各有对应材料。〔L3 第23条、第三至五章；L4〕 |
| 维持、变更、撤销、确认违法、确认无效、责令履行 | 在叙述行政复议决定或行政判决时按主文写。撤销原决定，不直接推出有关专利已授权或已无效。〔L3 第五章；L5 第六章〕 |
| 行政诉讼被告、被诉行政行为、行政争议 | 根据诉讼材料写行为、文书和当事人。复议后的被告身份按复议结果与适用规则核对。〔L5 第26条〕 |
