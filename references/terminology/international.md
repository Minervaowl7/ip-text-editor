# 国际制度和其他权利

先辨认权利类型、体系、地区和时点。涉及属地效力时分别核查主管机关记录。外国申请或者登记文件中的正式名称、编号和种类代码按原件抄写。法条和版本见[来源与版本](sources.md)。

## 国际专利、商标和外观设计

| 用语 | 怎样选 |
| --- | --- |
| 巴黎公约途径、国民待遇、优先权、各国专利独立 | 适用哪个制度就写哪个。“在先提交申请并主张优先权”描述行为，能否享有优先权另据法律和案件材料。各国专利分别查状态。〔I2 第2、4、4bis条〕 |
| PCT国际申请、受理局、国际局、国际阶段 | PCT是申请途径。报告可写“已提交PCT国际申请”，并标注受理局或国际申请号；不存在统一的“世界专利”或“国际专利”授权，境外库检索应写“外文专利文献”或“境外专利文献”，WO仅指PCT国际公布而非具体国家。〔I1 第3、10、21条〕 |
| 国际申请号、国际公布号、国家或地区申请号 | 照录来源字段。WO 文献号与授权国家或地区的授权公告号要分别存列。〔I1 第21条；G3 第一章；P3〕 |
| 国际检索报告、书面意见、国际初步审查报告 | 根据文书题名和 PCT 程序选择。报告、意见及之后各国审查结果各自列明。〔I1 第18、33、35条及实施细则；G3〕 |
| 进入国家阶段、指定局、选定局 | 说明实际进入的国家或地区、时间和编号。指定某国的记录并不确认已进入该国或获得该国授权。〔I1 第22、23、39、40条；G3〕 |
| 国际初步审查、国际初步报告、国内授权审查 | 国际阶段意见的术语和国内审查结论分别保留。涉及报告名称及约束力以所用文件和条约为准。〔I1 第33、35、37条；G3〕 |
| 海牙体系、外观设计国际申请、指定缔约方 | 国际申请、国际注册和指定地区的效力分别写。有关中国的程序按申请文书及细则核对。〔I5；P2 第十二章〕 |
| 马德里体系、基础商标、国际注册、指定、领土延伸 | 对照国际注册簿和指定成员本地记录。指定、暂时驳回、给予保护声明及撤销等按实际程序写。〔I4；T3 第五章〕 |
| 欧洲专利申请、欧洲专利授权、国家生效、单一效力 | 查证欧洲专利局和具体国家的记录。传统欧洲专利在相关国家的生效及后续状态，与登记取得单一效力的范围分别说明。〔I6〕 |
| 欧洲专利异议、各地无效程序、统一专利法院记录 | 按机关和程序写。由欧洲专利局处理的异议与各国家或统一专利法院程序分别核对。〔I6〕 |
| 同族专利、优先权关联、国际阶段与各国同族成员 | 写明数据库采用的同族口径。技术相关可按同族查找，权利要求、状态和期限要逐件确认。〔P3；I6；实务〕 |
| TRIPS协定、未披露信息保护 | 讨论最低保护标准可用条约用语。写中国法上的商业秘密要件时，按国内法和所涉案件写。〔I3 第39条；U1 第10条〕 |
| 马拉喀什条约、受益人、无障碍格式版、被授权实体 | 写明哪一种受益场景、作品和交换或制作行为。对于无障碍版本及利用依据，按具体法律或条约术语表达。〔I7 第2、3、5条；C1 第24条〕 |

## 其他权利、运营和行政保护

| 用语 | 怎样选 |
| --- | --- |
| 地理标志产品、地理标志集体商标或证明商标、地理标志专用标志 | 先查保护途径及登记信息。产品获保护、标志准予使用和注册商标权利各有记载，分别叙述。〔X1；T1 第16条；T3〕 |
| 产地范围、质量特色、技术要求 | 按获保护产品、适用文件和生产区范围写。市场上产自同一区域的商品是否符合规定按实际依据判断。〔X1〕 |
| 植物新品种、植物新品种权、品种权人 | 区分品种对象、申请及已授权权利。品种权与品种审定或登记、专利权分开。〔X2〕 |
| 繁殖材料、收获材料、实质性派生品种 | 界定材料和品种关系，注明引用的法规版本、作物和认定依据。只写植物相似不能推出实质性派生结论。〔X2〕 |
| 集成电路布图设计、布图设计登记、布图设计专有权 | 按登记申请、登记结果及专有权状态写。保留创作者与权利人区别。引用历史材料时核对2026年修订前后的条例。〔X3〕 |
| 首次投入商业利用、登记申请日、保护期 | 布图设计需分别写两个日期。保留先后及所适用版本，勿套用专利授权公告日起算的说法。〔X3 第17条〕 |
| 知识产权海关备案、扣留侵权嫌疑货物、侵权认定 | 备案、海关扣留、处理决定和行政或司法认定分别记录。写“侵权嫌疑”时保留待查含义。〔X5〕 |
| 展会投诉、涉嫌侵权展品、处理措施 | 说明展会投诉机构的处理及其证据。撤下展品不能直接改写成司法认定侵权。〔X8〕 |
| 技术进口、技术出口、自由或限制类技术、许可、合同登记 | 依技术及适用目录选用表达。出口前保密审查与技术进出口管理是不同手续，分别核对。〔X6；P1 第19条；P2 第8、9条〕 |
| 技术贸易措施、对外贸易中的知识产权保护 | 保留贸易措施的正式名称、发布机关、适用对象和时点。没有具体依据时写已知交易条件，不自行判断限制是否成立。〔X9 第五章〕 |
| 成果转化、技术交易、专利实施 | 数据以相应项目、合同及实施记录为准。转化成果可以包含多类权利及非专利技术，不能把项目数直接写成实施专利件数。〔X4 第2、16条；实务〕 |
