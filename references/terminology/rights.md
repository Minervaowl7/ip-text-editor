# 商标、著作权和商业秘密

同一份稿件可能涉及几类权利。先查事实指向哪类标识、作品或信息，再写申请、归属、使用或侵害。法条和版本见[来源与版本](sources.md)。商标条号所标T1为2019年修正文本。

> 注意：《中华人民共和国商标法（2026年修订）》（T2，共9章87条）自2027年1月1日施行。涉及新法或过渡期案件时，须对照T2核对条号与新增制度（使用义务、职权撤销、恶意抢注规制等），不得直接沿用下表中的T1条号。

## 商标及相关标识

| 用语 | 怎样选 |
| --- | --- |
| 商标、注册商标、注册商标专用权 | “商标”可指使用的标识。“注册商标”及“注册商标专用权”须核对注册及状态。避免把品牌知名度写成已注册。〔T1 第3、56条〕 |
| 商标注册申请、申请号、注册号、商标注册人 | 确认申请或注册资料及相应角色。号码按原件，只查到申请时表头写“申请号”。〔T1 第22、28、33条〕 |
| 商品商标、服务商标、集体商标、证明商标 | 按注册种类及实际使用方式写。地理标志还涉及专门保护途径，见[国际制度和其他权利](international.md)。〔T1 第3、16条；T3〕 |
| 指定商品或服务、初步审定的商品或服务、核定使用的商品或服务 | 依程序阶段和商标注册簿或公告选用。类别号不足以说明具体商品服务。〔T1 第22、28、56条；T3〕 |
| 类似商品或服务、同一种商品、类似群 | 近似或类似的判断按法律和相关事实写。数据库分组或尼斯分类属于分类依据，不能直接写成法律判断。〔T1 第30、57条；T3〕 |
| 受理、初步审定公告、核准注册、注册公告 | 按对应文书或公告写，保留实际阶段。网站只显示“已受理”时不写“已初审通过”。〔T1 第28、33条；T3〕 |
| 驳回注册申请、驳回复审、商标异议、不予注册决定 | 根据异议、驳回或不予注册的文书明确程序及主体。“商标复审”不足以区分复审的事项。〔T1 第33–35条〕 |
| 商标无效宣告、撤销、注销、续展 | 写明制度与实际处理结果。无正当理由连续三年不使用的撤销可在同行稿中简称“撤三”。申请撤销或申请续展和处理结果分别表述。〔T1 第40、44–50条；T3〕 |
| 驳回、异议成立、不予注册、准予注册 | 以决定主文和商品服务范围为准。部分商品或服务被驳回时，不省略范围。〔T1 第34、35条；T3〕 |
| 商标转让、变更注册事项、商标使用许可 | 转让与主体名称变更及许可使用分别写。合同、核准、公告及备案应据各自材料。〔T1 第41–43条〕 |
| 商标使用、作为商标使用、注册标记 | 结合标识和使用场景写明其识别来源的功能。符号、字号及内部商品编码是否构成商标使用需依案判断。〔T1 第48、57条；T3〕 |
| 商标相同或近似、商品相同或类似、容易导致混淆 | 三者应分清。表格里单列标志比对和商品比对。陈述侵权判断时注明适用的具体情形。〔T1 第30、57条〕 |
| 驰名商标保护、相关公众、在先权利、在先使用 | 说明请求、适用要件及已经查明的事实。“中华老字号”、一般知名品牌和驰名商标认定按各自依据写。〔T1 第13、14、32、59条〕 |
| 商标侵权、商标混淆、不正当竞争混淆行为 | 先确认当事人主张和所据条款。把标识、使用行为、权利基础和混淆判断分别写清。〔T1 第57条；U1 第7条；U4〕 |

## 著作权、许可和软件

| 用语 | 怎样选 |
| --- | --- |
| 作品、作品载体、内容素材、独创性 | 写清争议对象是表达、原件、复制件、数据素材还是思想构思。分析独创性时指出具体表达。〔C1 第3、20条；C2 第6条〕 |
| 著作权、著作权登记、登记证书 | 依材料写“完成作品登记”“取得登记证书”或“享有相关权利”。软件登记证明文件在相应规定中是登记事项的初步证明。〔C1 第2、12条；C2 第7条〕 |
| 作者、署名人、著作权人、受让人 | 按著作、署名、约定或转让材料分别写。署名和登记可作为权属证据，保留证据强度和异议。〔C1 第11、12、27条〕 |
| 合作作品、职务作品、委托作品 | 依据创作参与、工作任务和合同约定区分。明确主张的是作者身份还是某项著作财产权。〔C1 第14、18、19条〕 |
| 发表权、署名权、修改权、保护作品完整权 | 分别对应发表决定、署名、修改及完整性。未说明权项的“人身权益”可待核，不自行补成四项均受侵害。〔C1 第10条〕 |
| 复制权、发行权、信息网络传播权 | 复制、向公众提供原件或复制件、公众按选定时间地点获取，分别写清行为。线上发表、流媒体和链接不要一律写成“发行”。〔C1 第10条；C3〕 |
| 改编、翻译、汇编 | 同一材料可能涉及多种创作或使用。按具体行为写明使用了何作品、何部分、何种权利与许可。〔C1 第10、13、15、16条〕 |
| 表演者权、录音录像制作者权、广播电台电视台权利 | 确认保护对象及权利人。音乐作品、表演、录音制品和播出的节目分别核对。〔C1 第四章〕 |
| 许可使用、专有使用权、非专有使用权、权利转让 | 按合同及所涉权项写清使用方式、地域、期间、媒介和再许可约定。许可不当然改变权利归属。〔C1 第26–29条〕 |
| 合理使用、法定许可、合同许可 | 指定制度适用条件和案情，引用正文按原文。免费资料、标注来源或非营利使用各自不能单独推出合理使用。〔C1 第24、25条等〕 |
| 软件登记、软件著作权转让、软件著作权许可 | 区分登记事项与生效、归属主张及授权范围。“拥有软件著作权”宜与实际权属材料相符。〔C2 第7条及第三章〕 |
| 源程序、目标程序、软件文档、技术方案 | 写清比对的是代码、文档还是功能与实现方式。使用功能相同本身不能说明复制软件表达，也不能代替专利比对。〔C2 第3、6条；实务〕 |

## 商业秘密和不正当竞争

| 用语 | 怎样选 |
| --- | --- |
| 主张保护的信息、涉案信息、已认定的商业秘密 | 明确是当事人主张、待审查对象、报告意见还是生效裁判认定。保密协议列有某项信息时，可以写明约定范围。〔U1 第10条；U2、U3〕 |
| 秘密点、技术信息、经营信息、商业信息 | 用能定位的边界描述主张内容，如数据项、工艺步骤、参数组合或客户信息。保留整体组合及其各部分的关系。〔U1 第10条；U2 第1条；实务〕 |
| 不为公众所知悉、商业价值、相应保密措施 | 按本案事实分别写，核对评价的时点和接触范围。“保密”标记或签署协议，分别是措施的证据。〔U1 第10条；U2 第3–7条；U3〕 |
| 公开信息、公开信息的特定组合、可从公开渠道获得 | 写明实际查到的范围和时间。个别组成部分已公开时，仍按材料核对具体信息组合。〔U2 第3、4条〕 |
| 保密义务、保密措施、竞业限制 | 分清约定义务、管理措施和任职或从业限制。叙述时分别说明对象、主体及适用期限。〔U1 第10条；U2 第5、6、10条；M1 第501、509条〕 |
| 获取、披露、使用、允许他人使用商业秘密 | 按材料写具体行为、信息和主体。“接触过信息”只说明接触事实。将具体的获取或使用判断留给相应证据。〔U1 第10条；U2〕 |
| 接触可能性、实质上相同、侵害商业秘密 | 写清接触材料、比对对象及认定主体。相似外观、履历或岗位名称不能代替对具体信息的比较。〔U1 第10条；U2 第12、13条〕 |
| 自行开发、反向工程、合法取得 | 陈述依据、对象和过程。单凭公开购买产品不能推定反向工程已经完成。〔U2 第14条〕 |
| 有一定影响的标识、混淆行为、商业诋毁、虚假或者引人误解的商业宣传 | 分别写标识、商业行为、相关公众和依法限定的结果。不要把旧条文中的“知名商品特有名称”套给每一版本。〔U1 第7、9、12条；U4〕 |
| 行政查处、民事索赔、刑事追诉 | 写清程序阶段与机关。使用相应文书中的行为定性，收到投诉不能直接写成侵权成立。〔U1；U2；X7〕 |
