# 名称和简称

首次出现时按文种给出正式名称，后文可使用不产生歧义的简称。文件题名、引用、权利要求中的定义词、当事人名称和历史机构称谓以对应原件为准。材料只写简称而所指不明时，先查出处。法条和版本见[来源与版本](sources.md)。

| 正式名称或字段 | 可用简称或写法 | 使用条件 |
| --- | --- | --- |
| 中华人民共和国专利法 | 专利法 | 需要指明版本时写“《中华人民共和国专利法》（2020年修正）”。〔P1〕 |
| 中华人民共和国专利法实施细则 | 专利法实施细则、实施细则 | “实施细则”须能从本段确定所指。注明 2023 年修订时可与其他版本区分。〔P2〕 |
| 专利审查指南 | 审查指南 | 具体引用可写“《专利审查指南》第二部分第四章第6.4节”。涉及第84号局令修改的内容，标明所用版本或施行日。〔G1–G5〕 |
| 国家知识产权局 | 国知局仅适合内部简写 | 在报告、意见书和案例中可写“国家知识产权局”。“国务院专利行政部门”“管理专利工作的部门”分别依法律原文及权限使用。〔P1 第3、65条〕 |
| 专利复审和无效审理部 | 用文书中的机构名称 | “专利复审委员会”可保留在历史决定或引文中。陈述作出决定的机关时，照文书署名。〔G4 第一章〕 |
| 专利代理机构、专利代理师 | 代理机构、代理师 | 前者是机构，后者是人员。“专利代理人”在历史文件、引文或其他法域场景按原意处理。〔G1 第一章第4.1节〕 |
| 专利权评价报告 | 评价报告 | 用于确指该法定名称。商业尽调中的价值评估报告、专利检索报告和稳定性分析分别照题名写。〔P1 第66条〕 |
| 发明专利申请公布说明书、发明专利说明书 | 申请公布文本、授权文本 | 前者与申请公布相联系，后者用于已授权文献。表内保留文献号及种类代码。〔P3〕 |
| 审查意见通知书 | 审查意见、OA | “审查意见”也可指通知书里的具体意见。首次用 OA 时注明所指法域和文书。〔G2 第八章〕 |
| 复审请求审查决定、无效宣告请求审查决定 | 复审决定、无效决定 | “无效决定”表示文书类型时，结果仍须另写。可能维持，也可能全部或部分无效。〔G4 第二、三章〕 |
| 中华人民共和国商标法 | 商标法 | 用“2019年修正”或“2026年修订”识别文本。2026 年修订文本自 2027 年 1 月 1 日施行。〔T1、T2〕 |
| 商标局、商标评审委员会、国务院商标管理部门 | 依材料名称或所引条文简称 | 历史文书署名按原件。2019 年修正文本与 2026 年修订文本涉及机关的表述应按对应条文写。〔T1 第2条；T2 第4条〕 |
| 中华人民共和国著作权法 | 著作权法 | 一般沟通可说“版权”。法规题名、权项和证书按材料原称。〔C1〕 |
| 计算机软件著作权 | 软件著作权、软著 | 正式陈述可用“软件著作权”。“软著”可用于内部台账或通俗文稿。注明是登记件数还是权利情况。〔C2〕 |
| 中华人民共和国反不正当竞争法 | 反不正当竞争法 | 条号随版本核对。2025 年修订文本中的混淆行为、商业秘密分别见第7、10条。〔U1〕 |
| 中华人民共和国民法典 | 民法典 | 引用可写“《民法典》第862条”。合同编是编名，正文仍按对应条文准确引用。〔M1〕 |
| 专利合作条约 | PCT | 指条约或其国际申请途径时分别写“《专利合作条约》”和“PCT国际申请”。〔I1〕 |
| 保护工业产权巴黎公约 | 巴黎公约 | “巴黎公约途径”在申请方案中通常指按该途径分别申请并依条件主张优先权。写出具体申请行为。〔I2〕 |
| 与贸易有关的知识产权协定 | TRIPS协定 | 外文可用 TRIPS Agreement。具体争议仍应分别引用适用的国内法和条约条款。〔I3〕 |
| 专利实施自由分析 | FTO分析、自由实施分析 | 首次出现沿用委托书或报告体例，并明确分析产品、地域、日期和行为。“FTO”在同一报告中统一。〔R1〕 |
| 国际专利分类、合作专利分类 | IPC、CPC | 栏名和分类号按原数据库字段。分类号用于检索或标引，不能据此确认权利覆盖。〔P3〕 |
